# Simple Todo App

Files:

- `index.html` — main HTML file
- `styles.css` — styles
- `app.js` — JavaScript logic

Open `index.html` in your browser (double-click or use PowerShell `Start-Process`).

Features:

- Click the todo text or the checkbox to mark completed (strikethrough).
- Todos are saved to `localStorage` and persist across reloads.

PowerShell example to open:

```powershell
Start-Process 'C:\Users\t2b19\OneDrive\Documents\GitHub\RandomTask\todo-app\index.html'
```
